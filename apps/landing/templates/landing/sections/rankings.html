How scoring works
  • Verified shipped work (35): 12 points per completed project with pushed code, 4 per project in progress with pushed code.
  • Coding consistency (25): 1 point for each day you pushed code in the last 90 days.
  • Teaching (20): 4 points per public learning post, plus 1 per 10 signed-in readers (your own views never count).
  • Community (10): 1 point per follower.
  • Profile completeness (10): 2 points each for headline, about, skills, location, and a public project.
  • Logins, page views, and checklist clicks never add points.
