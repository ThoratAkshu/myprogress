Questions

Good to know.

Is MyProgress free?

Yes. Hosting code, publishing videos and articles, and appearing in the rankings are free for students and professionals.

Do I need to install anything?

No. Git works as it always does, and the video studio runs in a modern desktop browser such as Chrome or Edge.

How is my rank worked out?

Out of 100: verified shipped work (35), coding consistency over 90 days (25), teaching (20), followers (10) and a complete profile (10).

Can I keep projects private?

Yes. Every project and repository is private unless you make it public.

function sumEvens(nums) {
  let total = 0;
  for (const n of nums) {
    if (n % 2 === 0) total += n;
  }
  return total;
}

console.log(sumEvens([3, 4, 7, 10]));

    Developer mode
    Good to know.
    

    

    Is developer mode free?
    Yes, for every student and professional account.
    

    How do I turn it on?
    Sign in with this toggle on, or use the Developer mode toggle under Me once you're in. You can try it {{ dev.switch_limit }} times in {{ dev.switch_window }} minutes, and turn it off any time.
    

    Which languages?
    Questions come in {% for name, count in dev.languages %}{% if forloop.last %}and {% endif %}{{ name }}{% if not forloop.last %}, {% endif %}{% endfor %}. Problems, the dry run and the Code lab run Python and JavaScript in your browser.
    

    Does my code run on your servers?
    No. Python runs in your browser with Pyodide, and JavaScript runs in a sandboxed frame. When you submit a problem, your code and its result are saved to your account.
    

    What happens to my answers if I turn it off?
    They're kept. Turn developer mode back on and your answers, streak and submissions are where you left them.
